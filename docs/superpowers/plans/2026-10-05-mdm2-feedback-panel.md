# 新种子与多父代的反馈选位验证

固定在同一个 MDM2 85 aa 受体结构域，使用 1YCR、3EQS、3G03 三个实验复合物父代。完整肽为 13/12/12 aa；3EQS 和 3G03 实验坐标分别缺失最后一个 P/S。天然结构评价保留真实坐标，生成与预测用完整序列。

每父代比较 native-guided、native-random、predicted-guided、predicted-random，每臂3条，精确替换2位。guided选择有接触反馈的最低平均置信度2位；random从对应反馈来源的有接触位置均匀选2位。PepMLM top-k=3、温度1，排除父代残基再采样，不按PPL筛选。父代预测反馈只纳入通过质量过滤的参数模型，至少2/3通过才能进入该实验。

每个父代和子代用 AFM-v3 参数模型1/2/3，新seed=20261009、3次recycle、禁止提前停止、max_seq=256、max_extra_seq=512、无模板。全部共39条序列、117个复合物。共享同一受体MSA，删除所有原肽同源与paired行；肽长改变时只改其padding，不改受体序列、对齐或插入。

运行前发现新seed未松弛p53父代有两个单原子对<1.5 Å重叠。生成任何子代前统一加入官方ColabFold Amber有约束能量最小化：max_iterations=200、max_outer_iterations=3、tolerance=2.39、stiffness=10、CPU。保留所有原始坐标和未松弛父代诊断。上一轮21个预测也采用相同处理后复核，便于跨种子对照。

模型质量门槛维持ipTM≥0.7、肽pLDDT≥70、界面PAE≤10 Å、最小跨链重原子距离≥1.5 Å且有界面接触。改善必须父子在至少2个相同参数模型上同时通过质量过滤、这些配对模型的GraphPep中位数降低>0.05、并至少2个配对模型方向一致。该阈值是工程操作标准，不是亲和力或统计显著性。

所有采样位点、输入哈希、结构原文件、评分、反馈与源码快照保留。记录锚点F3/W7/L10是否被改变，以识别random组频繁破坏锚点的混杂。3个模型不是独立生物学重复，每组n=3只允许初步计算结论；此结果的目标仍是MDM2，不是NCAM1。
