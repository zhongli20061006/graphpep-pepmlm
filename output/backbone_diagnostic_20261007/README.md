# 固定/柔性肽主链对照

科学协议在新结构松弛和新 FoldX 分数产生前冻结。先执行 repeat 1 的 48 个结构技术试跑，满足身份、约束、数值和原始表条件后覆盖五次配对的全部 240 个结构。扩展不以“出现预期改善”为条件。

正式计算已完成，状态记录在 run_record.json、execution_state.json 与 execution.log；240/240 个结构有效，120/120 个 WT/突变体配对和 60/60 个柔性减固定差值齐全。技术门槛通过，独立原始数据审计通过（240 个结构、120 份共同加氢输入、480 张 FoldX 原始表）。对象为 MDM2–p53 WT/P27A/L22A。两组侧链处理相同；受体主链固定，柔性组肽主链使用弱位置约束。使用现有 OpenMM 8.6.1 CPU 环境和许可 FoldX。

主要结果：释放主链后，P27A 预期的正向增益仍未在任一完整种子中恢复（种子 20261011 为错误方向，20261012 不确定）；L22A 在两个种子、固定和柔性条件下均为预期方向。柔性减固定的 P27A 配对差值中位数为 +0.1044 和 +0.0917 kcal/mol，幅度不足以改变判断。几何上，P27A 的位置 8–11 alpha-like 残基中位数在柔性组从 1 增至 2，但 WT 参考结构也有相同变化，突变特异配对变化中位数为 0；O7···N11 距离中位数为 6.20→6.07 Å，没有结构达到 3.5 Å 代理阈值。严格可动原子力 RMS 验收为 35/240；其余 205 个未达阈值，虽结构及评分记录有效，科学解释需受此限制。结果与边界条件见 analysis/interpretation_zh.md，几何汇总见 analysis/backbone_conformation_summary.json，图见 analysis/fixed_flexible_comparison.png。

局部最小化不是 MD，也不模拟游离肽构象；本轮检验几何敏感性，不能验证完整结合自由能。

最终实现经科学协议与代码审查通过；独立运行的完整测试为 15 项通过（23.243 秒）。原始 FoldX 表中的五个残基数量字段使用 count 单位，能量字段使用 kcal/mol。
